---

## 🛡️ Reporting a Vulnerability

The VeriSight project takes software security, data privacy, and adversarial robustness seriously.

If you believe you have found a security vulnerability, an adversarial bypass against our forensic probes, or an unauthenticated remote execution vector:

1. **Do NOT publicly disclose the issue via GitHub Issues.**
2. Send an email with a detailed description, reproduction steps, and proof-of-concept payload to:
   **adityasantosh2026@gmail.com** with the subject tag `[SECURITY] VeriSight Vulnerability Report`.
3. Please allow up to 48 hours for an acknowledgment and response before taking any further action.

We appreciate responsible disclosure and will credit security researchers in our release notes upon validation and patching.
